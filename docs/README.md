## 建议阅读顺序

1. 先读 [CONTEXT.md](../CONTEXT.md)，确认这轮是 P0-Lite 还是完整 P0，以及验收口径。
2. 再读需求澄清，确认业务规则和 P0 边界。
3. 最后读方案设计，重点评审架构取舍、置信度闸门、退款子流程和数据飞轮。
4. 准备决定 P1 方向、找商家试用或做求职材料时，先按 [07-调研方案](./07-调研方案.md) 执行，不要直接扩功能。
