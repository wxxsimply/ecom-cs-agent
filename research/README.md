# 求职作品证据包

> 用途：把“我做了个客服 Agent”变成“我有数据、有访谈、有评测、有失败记录”。
> 目标人群：3–5 位电商售后从业者（主管/一线/老板/代运营）。

## 文件

| 文件 | 用途 | 什么时候用 |
| --- | --- | --- |
| [01-招募话术](01-招募话术.md) | 找 3–5 位从业者，含微信/小红书/脉脉/电话版本 | 本周 |
| [02-访谈提纲](02-访谈提纲.md) | 30–40 分钟行为访谈，含记录模板 | 约到人之后 |
| [03-材料请求与脱敏](03-材料请求与脱敏.md) | 要 5–10 张工单、政策、审批规则；脱敏与同意 | 访谈前发 |
| [04-评分表与证据登记](04-评分表与证据登记.md) | 5 分制、金额错误单列、证据 CSV | 每场访谈后 |
| [05-作品集叙事](05-作品集叙事.md) | 6 页结构、5 分钟演示、10 个追问 | 最后两周 |

## 配套数据

- [脱敏工单数据集](../data/eval/README.md)：75 条合成工单，50 dev / 25 holdout，含金额、人工标记、政策引用。
- 生成/校验：`python scripts/build_eval_tickets.py`、`python scripts/validate_eval_tickets.py`。
- 真实工单只放 `data/eval/private/`（已 gitignore），不提交。

## 三周怎么用

| 周 | 动作 | 产出 |
| --- | --- | --- |
| W1 | 按 01 招募，按 02 访谈，按 03 要材料 | 3–5 份记录 + 5–10 张脱敏工单 |
| W2 | 跑真实模型 + 数据集评测，按 04 评分 | 评测报告 + 指标表 |
| W3 | 按 05 写案例、录 5 分钟演示 | 作品集页 + 录屏 |

## 底线

- 不冒充平台/品牌，不承诺收益，不付费买数据。
- 不收集身份证/银行卡/客户完整信息；录音先同意。
- 合成数据必须标 `synthetic`；真实工单不提交、不外传、90 天删除。
- 没跑真实模型，就不写“准确率”；没商家试用，就不写“已落地”。
