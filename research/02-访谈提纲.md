# 访谈提纲（30–40 分钟）

> 只问行为，不问态度。不要问“你觉得 AI 有用吗”“你会用吗”——答案一定是礼貌的“会”。
> 目标：拿到 1 个最近一单的完整流程、3 个数字、1 个卡点。

## 0. 开场（3 分钟）

- 自我介绍：求职作品，不是卖产品。
- 说明：匿名、不涉客户信息、可随时叫停；录音仅本地整理，之后删除。
- 确认：30 分钟是否够；对方希望怎么称呼。

## 1. 背景（5 分钟）

1. 你们做哪些渠道（自营商城/平台店/微信/企微）？什么类目？客服几个人？
2. 你负责什么？哪些事必须你签字？
3. 每天大概多少咨询、多少售后？

## 2. 还原最近一单（15 分钟，核心）

> 请挑**最近一单**退款/换货/物流异常，从客户进线讲到闭环。

追问（按顺序，别跳）：

1. 客户怎么进来的？原话大概是什么？
2. 你开了哪几个系统？分别查了什么？
3. 依据哪条政策？政策谁写的、多久更新一次？
4. 谁批准？金额怎么定？退到哪里？
5. 花了多久？哪一步最卡？
6. 如果重来一次，你希望哪一步被自动化？哪一步绝对不能让 AI 做？

## 3. 量化（5 分钟）

- 月咨询量 / 售后单量 / 退款金额；
- 每单人工分钟数，尽量拆成“查 / 判 / 办 / 回”四段；
- 误退、纠纷、平台处罚、差评各几次；
- 新人多久能独立处理售后。

## 4. 工具与规则（5 分钟）

- 现在用平台客服 / SaaS / Excel / 群聊？哪些好用、哪些不好用？
- 为什么没换？换的成本是什么？
- 政策从哪来、多久变一次、谁维护？政策用错出过什么事？
- 如果不用任何工具，你打算怎么解决？

## 5. 收尾（5 分钟）

- 如果有一个工具能做到【具体动作】，你愿意拿什么来试？（脱敏工单/测试账号/1 小时）
- 你愿意为它替代哪笔成本（人力/外包/罚款）？
- 有没有哪类单是“看起来简单、实际最容易出错”的？
- 能不能推荐一位一线客服或同行？

## 6. 提问规则

| 要 | 不要 |
| --- | --- |
| “最近一单怎么走？” | “你觉得这个功能怎么样？” |
| “花了多久？哪一步卡？” | “你会用 AI 吗？” |
| “能给我看下后台截图吗？” | “你们数据能发我吗？”（第一次） |
| 沉默 3 秒，等对方补充 | 对方一停就接着问下一题 |
| 复述确认：“所以是 X 先、Y 后？” | 替对方总结成你想要的答案 |

## 7. 访谈记录模板

```markdown
# 访谈 A（自营商城 / 鞋类 / 客服主管 / 2026-11-05）

## 背景
- 渠道：自营商城 Web + 企微
- 团队：4 人；日咨询 ~120；售后 ~25/日
- 系统：自建 OMS + 顺丰查询 + 手工 Excel

## 最近一单（原话）
> “用户说鞋开胶，我先查订单，再问仓库能不能退，最后手工退款，前后 18 分钟。”

## 量化
- 每单人工：查 3 分 / 判 5 分 / 办 7 分 / 回 3 分
- 月退款：约 40 笔，金额 1.2 万
- 误退：近 3 个月 0 次；纠纷 2 次

## 工具与规则
- 用过某 SaaS，政策维护太重弃用
- 不肯换的原因：迁移成本 + 数据安全

## 卡点（原话）
> “最怕客户说‘你们看着办’，政策没写这种情况。”

## 试用意愿
- 愿意提供 10 张脱敏工单 + 1 小时
- 不愿付费；愿用“减少加班”换

## 材料
- [ ] 政策文档截图
- [ ] 工单样例
- [ ] 后台字段截图（打码）
```

## 8. 访谈后 30 分钟整理

1. 写 3 句原话（不要转述成结论）。
2. 记 3 个数字（单量、分钟、金额/纠纷）。
3. 标 1 个“AI 绝对不能做”的点。
4. 判断：这个人是 A（有痛点+有材料）、B（有痛点无材料）、C（无痛点）。
5. 更新 `research/04-评分表与证据登记.md` 的证据表。

## 9. 常见错误

- 访谈变成产品演示：对方出于礼貌夸你，信息量为零。
- 只问“痛点”，不问“最近一单”：得到的都是抽象抱怨。
- 诱导：“你是不是觉得退款很麻烦？”——对方会顺着你说。
- 记录里写“客户很痛”却没有原话和数字——证据表无法引用。
- 承诺保密却把截图发群里——一次就毁掉信任。
